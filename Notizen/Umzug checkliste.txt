===========================================================
TEIL B - AUFBAU ZU HAUSE (mit Server)
===========================================================

B1. Hardware anschliessen
	[ ] Server aufstellen (Belueftung beachten, nicht im Schrank)
	[ ] Netzwerkkabel zur FRITZ!Box anschliessen
	[ ] Server einschalten und im Netzwerk suchen

B2. Netzwerk von Proxmox anpassen
	WICHTIG: Die aktuelle Konfiguration ist fuer die Internetfreigabe
	des Laptops eingerichtet (192.168.137.x). Zu Hause gilt ein
	anderer Adressbereich (192.168.178.x).
	[ ] /etc/network/interfaces auf dem Proxmox-Host anpassen
	[ ] Vorher eine Kopie der Datei erstellen:
	    cp /etc/network/interfaces /etc/network/interfaces.backup
	[ ] Netzwerkdienst neu starten oder Server neu starten
	[ ] Proxmox-Weboberflaeche vom PC aus oeffnen
	[ ] Kontrollieren, ob die VM startet und Internet hat

B3. Feste IP-Adressen vergeben
	[ ] In der FRITZ!Box unter Heimnetz > Netzwerk den Server suchen
	[ ] Option aktivieren: "Diesem Netzwerkgeraet immer die gleiche
	    IPv4-Adresse zuweisen"
	[ ] Dasselbe fuer die Ubuntu-VM
	[ ] Adressen notieren:
	    Proxmox: ______________
	    Ubuntu-VM: ______________

B4. Nextcloud auf die neuen Adressen umstellen
	[ ] In den Ordner /srv/nextcloud wechseln
	[ ] trusted_domains anpassen:
	    docker compose exec -u www-data app php occ \
	      config:system:set trusted_domains 1 --value=192.168.178.XX
	[ ] overwrite.cli.url anpassen:
	    docker compose exec -u www-data app php occ \
	      config:system:set overwrite.cli.url \
	      --value=http://192.168.178.XX:8080
	[ ] In der Datei .env den Wert TRUSTED_DOMAINS anpassen
	[ ] Container neu starten: docker compose up -d
	[ ] Nextcloud im Browser oeffnen und Anmeldung testen

B5. Selbstpruefungen kontrollieren
	[ ] Administrationseinstellungen > Uebersicht oeffnen
	[ ] Kontrollieren, ob die Fehler verschwunden sind, die
	    vorher wegen der Internetfreigabe entstanden sind
	    (WebDAV, .well-known, OCS, Schriftarten, Datenverzeichnis)
	[ ] Verbleibende Warnungen im Journal notieren


===========================================================
TEIL C - VPN EINRICHTEN
===========================================================

C1. Voraussetzungen pruefen
	[ ] Ist die oeffentliche IPv4-Adresse aktiv?
	    Kontrolle: Internet > Online-Monitor, die Adresse darf
	    nicht mehr aus dem Bereich 100.64.x.x stammen
	[ ] Kontrolle von aussen: Die IP-Adresse mit dem Mobilfunknetz
	    (ohne WLAN) anpingen oder eine Webseite wie
	    "wie ist meine ip" vergleichen

C2. WireGuard auf der FRITZ!Box einrichten
	[ ] Internet > Freigaben > VPN (WireGuard) > Verbindung hinzufuegen
	[ ] Typ: Einzelnes Geraet (fuer jedes Smartphone eine eigene
	    Verbindung, nicht dieselbe mehrfach verwenden)
	[ ] Name der Verbindung sprechend waehlen (z.B. Handy-Yurii)
	[ ] QR-Code mit der WireGuard-App auf dem Handy scannen
	[ ] Konfigurationsdatei sicher aufbewahren

C3. VPN testen
	[ ] Test 1: Verbindung im eigenen WLAN aufbauen
	    (funktioniert meistens, sagt aber wenig aus)
	[ ] Test 2: WLAN am Handy ausschalten und ueber das
	    Mobilfunknetz verbinden - das ist der richtige Test
	[ ] Ueber VPN die Nextcloud-Adresse im Browser oeffnen
	[ ] Ueber VPN in der Nextcloud-App anmelden
	[ ] Ein Foto hochladen und die Geschwindigkeit messen
	[ ] Verbindung fuer alle drei Benutzer einrichten und testen

C4. Sicherheit
	[ ] Zwei-Faktor-Authentisierung in Nextcloud aktivieren
	[ ] Kontrollieren, dass Nextcloud NICHT direkt aus dem Internet
	    erreichbar ist (kein Portforwarding auf Port 8080)
	[ ] Starke Passwoerter fuer alle drei Benutzer
	[ ] Fail2ban oder die Brute-Force-Schutzfunktion von
	    Nextcloud kontrollieren
